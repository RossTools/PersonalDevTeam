# Where to go next

You've installed PDT, connected an agent, added a project and taken a ticket from idea to merge. From here:

- **Run several tickets at once.** Each gets its own branch and folder, so agents don't collide. The board shows
  where each one is. See [Tickets and the board](../using-pdt/tickets-and-the-board.md).
- **Try a branch before it merges.** Set up **Run** for your project, then start any branch on its own port. See
  [Run configuration](../automation/run-configuration.md).
- **Ask the PM.** Open **Project manager** in the rail and ask it to plan a feature into tickets, tidy the backlog or
  say what's in flight. See [The PM](../automation/the-pm.md).
- **Automate the hand-offs.** Turn on the **Pipeline** for a project, so agents review and test each other's work
  before you accept it. See [Workflows](../automation/workflows.md).
- **Check in from your phone.** Set up remote access over Tailscale. See
  [Remote access](../your-machine/remote-access.md).
- **Something not working?** See [Troubleshooting and FAQ](../troubleshooting/troubleshooting.md).
