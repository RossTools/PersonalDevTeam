Conflicts with the base branch are fixed once, when a ticket is next to merge: before that the ticket shows "Conflicts with main (deferred)" without interrupting its agent, and at the merge PDT merges the base in itself, regenerates lockfiles and generated code you list under `[[merge.regenerate]]` in `.pdt/project.toml`, and sends only real conflicts to an agent, so far fewer CI runs and agent turns go into keeping branches up to date. Set **When to resolve conflicts** to **Immediately** in a project's settings to keep the old behaviour.
