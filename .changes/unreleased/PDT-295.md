PDT no longer installs or offers workflows only for PDT's own repository (PDT bug triage, PDT pull request review, PDT nightly release, PDT missing nightly). If you have them, they stay as your own workflows, unchanged and still enabled, and PDT no longer updates them; the Triage new GitHub issues, Review outside pull requests, Report failed workflow runs and Report a missing scheduled release templates do the same for any repository.
