Settings › MCP servers: add an MCP server once and every agent gets it, in conversations and terminals, with keys taken from your secrets. Remote servers that use OAuth sign in once in PDT, and you can allow, ask or block each of a server's tools (search Slack, never post). MCP servers you already added for workflows stay workflow-only: tick **Agents** under **Who gets it** to give one to your agents.
