OhMyPi (`omp`) is now a built-in agent: once `omp` is installed and has a model, pick "OhMyPi" anywhere you pick an agent (a new tab, ticket Start, personas) to run it as a conversation, with its command and file approvals and its questions in PDT. Errors from ACP agents now show their details (such as omp's "No model selected") instead of just "Internal error".
