Cursor is now a built-in agent: once the Cursor CLI is installed and signed in (`agent login`), pick "Cursor" anywhere you pick an agent (a new tab, ticket Start, personas) to run it as a conversation, with PDT's tools, its command and edit approvals, its questions and its plans in PDT. Cursor's own "Ask" mode is read-only, so PDT keeps Ask, Accept edits and Bypass itself and uses Cursor's Plan mode for Plan.
