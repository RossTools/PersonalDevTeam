Forges are now plugins: a project's forge is the one its `.pdt/project.toml` names or the one that claims its `origin`, and GitHub issue triage, the GitHub workflow steps and the "Connect GitHub" Inbox item all go through it. Existing GitHub and local projects work as before; a `forge = "…"` naming a forge this PDT has no plugin for now falls back to the origin.
